週報小幫手 使用說明
====================
【下載】
到 https://github.com/iling1114-pixel/Weekly_Report_Assistant/releases/latest
下載「週報小幫手 vX.X.X.zip」

【安裝】
1. 把整個「週報小幫手」資料夾解壓縮到桌面（或任何你有寫入權限的地方）
   ※ 不要直接在 zip 裡面點開，也不要放到 C:\Program Files
2. 雙擊資料夾裡的「週報小幫手.exe」
3. 第一次開會跳出「個人設定」，填好後按「儲存」：
   - 週報表頭：例「王小明 UI/UX設計師」
   - 寄送方式：選 Outlook 或 Gmail（見下方【寄信】）
   - 收件人、副本：主管與同事的 Email（多位用 ; 隔開）
   - 郵件內文：把簽名改成你的姓名與 Email
   - 專案：每行一個，依週報上的順序
   - 簡稱：每行一個「簡稱=全名」，例「北專=台北新案專案」，工作紀錄裡寫簡稱也認得
   - 外觀：淺色或深色
   之後要改，按右上角「⚙ 設定」

【寄信】
兩種方式都只會幫你開好郵件，不會自動寄出，確認後自己按「傳送」。
- Outlook：需要「Outlook（傳統版）」；新版 Outlook 開不起來。週報 Word 會自動附上。
- Gmail：會用瀏覽器開一封 Gmail 草稿，同時打開週報所在的資料夾並選好檔案，
  請把週報 Word 拖進信裡當附件（Gmail 沒辦法自動附檔）。

【注意】
- 第一次開若出現 Windows「已保護您的電腦」：按「其他資訊」→「仍要執行」
- 若跳出「智慧型應用程式控制已封鎖」之類的訊息、而且沒有「仍要執行」可以按：
  代表你的 Windows 11 開了「智慧型應用程式控制」，這台電腦無法執行本程式。
  不建議為此關掉它（關掉後就不能再開回來），請聯絡提供程式給你的人。
- 產生的週報 Word 會存在資料夾裡的「週報」子資料夾
- 你的資料都存在這個資料夾裡，換電腦時整個資料夾一起帶走：
  todos.json（待辦）、settings.json（設定）、工作紀錄草稿.txt（還沒產生週報的工作紀錄）、
  window.json（視窗大小位置）

【更新版本】
有新版時，程式底部會出現「有新版本 vX.X.X」，按「下載」會打開下載頁。
1. 下載 zip、解壓縮
2. 把裡面的檔案全部複製，貼到原本的資料夾，選「取代」
todos.json、settings.json、工作紀錄草稿.txt、window.json、週報資料夾不要刪，資料就會保留。
